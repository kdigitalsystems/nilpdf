Frequently asked questions

Is NilPDF really free?

Yes. Every tool is free to use, with no account, no usage limits, and no paywalled features.

Do my files get uploaded anywhere?

No. All processing happens locally in your browser using a PDF engine compiled to WebAssembly. Your files are never sent to a server.

Is there a file size limit?

There's no hard limit enforced by NilPDF, but very large files are constrained by your device's available memory since everything runs in your browser. See the browser compatibility page for details.

Do I need to install anything?

No. NilPDF runs entirely in the browser tab you're on right now — no extension, app, or sign-up required.

What happens if I close the tab while a file is processing?

Processing stops immediately, and since nothing is ever uploaded, no partial file exists anywhere. Just reopen the tool and try again.

          Waiting for a PDF.
          Marked pages are flattened into an image. Any page you mark, with a black box or just a text note, is rebuilt from a high-resolution image of that page with the box and notes permanently baked in. The original text on that page is discarded, not just covered, so it cannot be selected, copied, or extracted afterward, and the page loses its selectable text. Pages you don't mark at all keep their original text as-is.

          Passwords don't match.

          NilPDF cannot recover forgotten passwords. Everything happens on your device, there's no copy on any server to reset it from. If you lose this password, the file cannot be unlocked by NilPDF or anyone else.
          Waiting for a PDF.
          NilPDF cannot discover, crack, or bypass a password it doesn't have. This only removes encryption from a PDF you already have the correct password for. If you don't know the password, NilPDF can't recover or guess it, there is no way around that here.
